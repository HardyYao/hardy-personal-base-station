# 机遇

事情发生在今年五月份的时候，今年五月份，我的一些奇妙际遇突然开始多起了。

五月的某一天，前同事想拉我去他们团队工作，我因为想在目前这家公司做完自己的项目，婉拒了。

同一周的周六晚上差不多八点的时候，我以前在惠州实习一家公司的老板——郭老师发了一些语音消息给我，他先是问我，自媒体赛道探索得如何了，之后主要跟我说了一下关于金融和量化投资的事情，他觉得我挺适合这条赛道的，因为我爱学习、会思考、肯钻研，他团队最近在 AI 的加持下，有了突破性的进展，打算要扩大规模了，需要这方面的人才。

他建议我业余时间了解一下这个赛道，有问题可以咨询他，要是觉得合适的话，可以去他公司。

我也跟他说了，我这边现在公司的自研项目，很多也初步成型了，不过还需要一两年时间才能全部搭建完，我还是蛮想把这边的项目做完的。

然后业余时间我会探索一下量化投资，或许等到这边系统做完的时候，就刚好差不多了。

郭老师觉得没啥问题，我可以按照自己的节奏去探索，等到时候觉得合适的话，再去他们公司发展。

可能也是他自己的公司，招不招人，他说了算，所以我早一点去、晚一点去 都可以吧。

他说手工交易员的话，培养起来得五到十年，不过量化的话，因为有程序基础在，只要肯钻研、有悟性，一两年就足够了。

如果过个一两年真的去惠州了，那以我到时候的储蓄水平，再加上郭老师那边的上班节奏，那简直爽的飞起，生活质量可以拉得很高了。

算起来，今年是认识郭老师的第九年了，时间过得真快呀！感觉郭老师对我确实是比较关注，不管科技再怎么进步，信任这种东西，都还是需要长时间积累的。

这感觉真舒服，只要我能玩得转量化，下一个去处基本上就定下来了，而且到时候就不用匆忙入职了，先玩一个月再说！

# 自我分析

相比起以前面对这些机遇时的谨慎和担忧状态，现在的我，变得洒脱了许多。

以前的我面对这样的机会，大概会有两种可能并存的状态：

一种是**过度评估**。郭老师一说，我可能会很快在脑子里把这件事放大，开始想"要不要现在就认真学？""万一我学不会量化怎么办？""时间来不来得及？"然后因为这个机会在脑子里占的比重越来越大，反而产生焦虑，最终变成内耗。

另一种是**讨好式的配合**。因为是信任的人给的机会，以前的我可能会不自觉地想"我不能辜负他的期待"，继而在还没想清楚自己是否真的想要的时候，就先把姿态摆出来了。

而现在我的想法是——先把公司这边的项目做完，业余时间探索一下量化，"早一点去、晚一点去都可以"。


我认为我现在能够坦然面对郭老师所提供的新机会，有三个关键因素：

1、具备一定的经济基础，拥有足够的安全感了。

这种安全感不光是经济层面的，还有这几年自我探索之后，内核越来越稳定所带来的内在安全感。

这种安全感，使我不再那么害怕尝试新事物。

2、我成事的次数越来越多，信心越来越充足了。

- 从第一份正式工作开始，在完全不懂 Java 的情况下作为团队核心项目的主力开发人员，到离职前才发现自己将近一年来都把这个项目的业务逻辑装在自己的大脑里。
    
- 从考研失败，跌入谷底到重新找到工作，在两周内融入一个大项目团队，登上项目组荣誉榜。
    
- 在宝能的时候，一度成为产品经理和其他团队争抢的开发人员。
    
- 在上家公司，成为多个项目组的人只要一遇到问题就会想到找我的角色。
    
- 在目前这家公司，从无到有搭建起了MES、SCM、工检模和WMS等系统的基本框架，到现在，MES和工检模系统过半的功能已开发完成，SCM和WMS也接近半成品，公司所有的自研系统，都是我部署起来的，整体架构，我最熟悉。从刚进公司时对业务的懵懵懂懂，到熟悉公司大部分的业务逻辑，我只用了将近一年的时间，而在我入职两年的这个时间节点上，我在此条道路上，已经越走越远了。
    
- **凭一己之力解决了家庭的大部分经济问题。**
    
- **个人数字资产积累方面：八年记账数据、两千多条flomo笔记、数十篇上千字的文章······**
    
- **坚持做自己在《30岁学会的30件事》这篇文章里面提到的六件绝对不会错的事情多年······**
    

3、最近对于自己业余时间注意力的掌控，有了比较大的突破，只要是自己认定的事情，就有把握能够投入相应的注意力进去，因而做决策时，会果断许多，不会因为担心自己无法兑现承诺而产生动摇。

尤其是在引入“预决策”之后，真的获得了飞速进步。
