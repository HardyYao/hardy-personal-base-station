# 前言

《富可敌国》这本书，令我感触最深的有两点：



1、加深了我对于长期资本管理公司的理解。



先前看《解读量化投资》的时候，我觉得长期资本管理公司失败的主要原因在于：过高的杠杆率以及缺乏风险管控意识，看了《富可敌国》后，我发现长期资本管理公司并不缺乏风险管控意识，相反，这家公司很重视风控，问题在于，他们的风控太依赖于数学公式、缺乏对于极端事件的缓冲了。



根据长期资本管理公司的推算，他们破产的概率小到几乎不可能会发生，但问题在于，他们计算时所依赖的数据，都是一些历史数据，而对于未来，他们一无所知，这个结果本身就是存疑的。



再者，即便他们的计算结果是靠得住的，但不管多小概率的事件，只要发生了，那就是百分之一百的灾难性事件，所以从一开始就不能寄希望于小概率事件不会发生，而是提前做好应对最糟糕事件的准备，使自己能够继续留在牌桌上。



2、我对索罗斯这个人的印象有了很大的改观。



之前我对于索罗斯的印象，主要是：金融巨鳄、1997年亚洲金融危机纵火犯。



而看了这本书，我才了解到了索罗斯的另一面。



2\.1、**人格的撕裂。**这是贯穿全书索罗斯故事最核心的张力——他同时是投机者和救世主，这两个角色在俄罗斯篇达到最激烈的冲突：他一边在分析俄罗斯财政危机，一边秘密借钱给政府、买入卢布资产，最后亏损10\-20亿美元，却在书里写道"我对帮助俄罗斯走向开放社会的努力并不后悔"。



2\.2、**反射理论**不只是投资哲学，它其实是波普尔的认识论在金融市场的翻版——人无法客观感知现实，而这些不完整的感知本身又在改变现实。这让索罗斯看待市场的方式，从一开始就和有效市场假说的信徒截然不同。



以上这些，使我对这个人充满了好奇，很想去看更多关于他的书籍，了解一下他的人生轨迹。

|1952年|行业影响|马科维茨发表《投资组合选择》，现代投资组合理论诞生，其核心思想与琼斯的速率（波动率）对冲方法高度契合——但琼斯早于理论10年独立发明并实践。||
|1961年|投资创业|为不超100人的投资者限额，创建第二家合伙公司；同年发给合伙人的内部文件中详细阐释速率（beta）概念，系统解释套期保值的数学逻辑。||
|1966年|基金业绩|《财富》杂志发表溢美报道，称其为最好的职业投资经理人，对冲基金概念开始广为人知，模仿者蜂拥而至。||
|1968年顶峰|行业影响|《纽约》杂志封面文章尊称琼斯为对冲基金鼻祖；彼时约有40家效仿公司，到1969年估计达200-500家，整个产业管理规模约110亿美元。||
|1969-1970年|危机衰退|美联储收紧货币，股市大跌。琼斯的团队未能及时对冲，至1970年5月亏损客户35%资金，跑输大盘。对冲基金实质上已抛弃对冲，蜕变为高杠杆牛市赌局。||
|1969-1974年|危机衰退|整个第一个对冲基金时代终结：28只最大对冲基金资产蒸发三分之二；从200-500家降至150家，1973-1974年危机后大多数被淘汰。琼斯合伙公司资产从逾1亿元跌至3500万。||
|1978年后|行业影响|《机构投资者》杂志1977年撰文置疑对冲基金是否还存在，直到1984年才确认仅剩68只。琼斯个人逐渐淡出，但其创立的绩效提成+自有资金跟投的激励结构被所有后继对冲基金沿用至今。||

# 乔治·索罗斯人生时间线
| 时间                  | 领域   | 关键事件                                                                                                                               | 备注                     |
| ------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| 1930年               | 早年成长 | 出生于匈牙利布达佩斯一个富裕的犹太家庭。                                                                                                               |                        |
| 二战期间                | 早年成长 | 纳粹占领布达佩斯期间，离开家人假称自己是基督徒躲在父亲熟人家中幸存。亲眼目睹街头惨遭虐杀的尸体，在极端压力下为家人谋生，早年遭遇深刻塑造了他对不确定性和生存的认知。                                                 |                        |
| 1947年               | 早年成长 | 不到17岁，独自离开匈牙利前往伦敦寻找未来，与父母告别时不确定是否还能再见。在伦敦先后做洗碗工、房屋油漆工、餐馆工，勉强维持生计。                                                                  |                        |

| 1956年               | 投资起步 | 设法来到纽约，打算在华尔街熬5年存够钱，回去做哲学家。但他很快发现自己极擅长投资，难以割舍。                                                                                     |                        |
| 1967年               | 投资起步 | 成为纽约知名经纪公司安贺-布莱施洛德的欧洲股市研究组组长，建立起在华尔街的初步声望。                                                                                         |                        |
| 1969年               | 投资起步 | 推出400万美元的多空选股基金，命名为双鹰基金，在布莱施洛德的庇护下运作。投资方法已开始融合波普尔哲学与市场观察——即他后来称为反射理论的雏形。                                                           |                        |
| 1970年               | 学术思想 | 在投资笔记中，索罗斯用明确的反射术语解释房地产投资信托基金的运作：关键不是收入预期，也不是单纯的心理，而是两者之间的相互强化循环，直到泡沫破裂。基金在REIT上升时做多、崩溃时做空，两段均获利。                                  | 反射理论首次明确应用于实战          |
| 1973年               | 宏观交易 | 离开安贺-布莱施洛德，与吉姆·罗杰斯合伙成立自己的公司。发现1973年阿以战争改变了国防业格局，大量买入洛克希德等国防股；发现金融管制放松正重塑银行业，重仓银行股，均大获全胜。座右铭：先投资，后调查。                               |                        |
| 1978年               | 投资业绩 | 基金更名为量子基金，资产已积累至3.81亿美元，约为初始资金的100倍。尽管20世纪70年代股市整体不佳，量子基金的回报依然惊人。                                                                  |                        |
| 1980年               | 投资业绩 | 量子基金回报率超过100%，索罗斯已积累逾1亿美元个人财富，同时成为慈善家。《机构投资者》杂志于1981年称其为世界上最伟大的基金经理。                                                               |                        |
| 1981年               | 危机挫败 | 由于解雇罗杰斯后分心寻找接班人，投资业绩猛然下滑。量子基金当年亏损23%——基金史上首次年度亏损。资本规模由4亿美元缩水至2亿美元，索罗斯遭遇严重挤兑潮。同年9月，他将剩余资金委托他人管理，宣布暂时退出，休假反思。                        |                        |
| 1984年               | 宏观交易 | 休假结束，重新全职投资。在心理学家的帮助下处理了部分心魔，放弃以身体信号（背痛）作为市场信号的方式，转而通过写投资日记来提高判断力。                                                                 |                        |
| 1985年8月             | 宏观交易 | 开始坚持记投资日记（后收入《金融炼金术》）。判断里根政府新团队决心让美元贬值，加之基本面利率下行，做空美元建仓。初期遭遇亏损约2000万美元，仍坚守头寸。                                                      | 这是书中最详细描述的一次宏观交易决策过程   |
| 1985年9月22日          | 投资业绩 | 广场协议签署——五国财政部长承诺协调干预促使美元下跌。索罗斯一夜获利3000万美元，此后拒绝兑现利润，在广场协议发出信号后继续大幅加仓日元和德国马克。4个月内量子基金增长35%，获利约2.3亿美元。                                | 索罗斯称此为生命中的巨大成功         |
| 1987年5月             | 学术思想 | 出版《金融炼金术》，将投资日记公开。书中首次系统阐述反射理论，将索罗斯确立为对冲基金行业的精神导师。保罗·都铎·琼斯要求员工必读此书，并将自己黑色星期一的交易策略部分归功于它。                                           |                        |
| 1987年9月             | 危机挫败 | 接受《财富》杂志封面采访，表示美国股市被高估，但崩盘将先从日本开始，并非美国。这一判断导致量子基金在美股大量持多头。                                                                         | 索罗斯后来承认这是一个代价惨重的错误判断   |
| 1987年10月19日         | 危机挫败 | 黑色星期一。道琼斯指数单日暴跌22.6%。索罗斯因基金规模过大，无法像德鲁肯米勒那样迅速出手，在流动性差的套利垃圾股上损失约2亿美元。一周内量子基金从盈利60%变为亏损10%，市值蒸发8.4亿美元。                                |                        |
| 1987年底              | 投资业绩 | 黑色星期一后，索罗斯迅速反弹。瞅准机会再次做空美元，大胆加杠杆，如同什么都没发生一样。美元随即下跌，赌局奏效。量子基金全年最终盈利13%。《金融世界》杂志将索罗斯列为华尔街年度收益第二名。                                     | 这段反弹被索罗斯的粉丝称为其最突出的成就   |
| 1988年秋              | 宏观交易 | 说服斯坦利·德鲁肯米勒加入索罗斯基金管理公司。德鲁肯米勒有选股、经济与技术分析三项技能，与索罗斯形成互补搭档，此后共同执掌量子基金近12年。                                                             |                        |
| 1992年9月16日（英国黑色星期三） | 投资业绩 | 德鲁肯米勒主导做空英镑，索罗斯建议全力以赴，头寸规模扩大至约100亿美元（约为基金资本的2.5倍）。英国政府在捍卫英镑数小时后宣布退出欧洲汇率机制，英镑大幅贬值。量子基金单笔获利约10亿美元，索罗斯由此获得逼垮英格兰银行的美誉。                 | 对冲基金历史上最著名的单笔交易        |

# 个人感悟

---

> 即使在20世纪60年代，那时华尔街刚刚摆脱萧条后的萎靡不振，大家也会惊奇地发现纯粹的努力将一个人区别于众人是多么容易。琼斯的选股人之一艾伦·德雷舍（Alan Dresher）想出了在公司文件刚出来的时候就直接去美国证券交易委员会办公室查看的办法。他的过人之处在于他是唯一有这个想法的人，而华尔街的其他人都在等着从邮局寄来的那一大沓文件。
> 
> 



不管在哪里，只要在某方面比别人多花一点心思，就足够为自己赢得更多机会了。

---

> 每个伟大的投资者的优势都是注定要消失的，这只是早晚的问题。他的技巧被竞争对手了解并模仿，他不能再宣称自己比市场更有效。
> 
> 



再高明的策略也总会有失效的时候，要想继续留在牌桌上，就要持续不断地进化下去。

---

> 市场越增长，琼斯的“表现跟踪奖励机制”对那些冒最大风险的市场经理的奖励就越多，但这个体制缺乏在灾难发生之前退出的机制。
> 
> 



原本很有效的激励机制，在没有做好风险管控的情况下，也可能会变成引爆“恶性黑天鹅事件”的导火索。

---

> 索罗斯用更智能的东西取代了后背痛的信号。从1985年8月起，他一直坚持记下他的投资想法，希望这种记录想法的做法会使他提高判断力，由此而产生的“实时实验”密集、重复，而且充满了对始终未实现情况的深刻反思，这也是一个对工作中的投机者的真实写照。此外，索罗斯的日记记下了他的一个最伟大的成就——对美元的赌注，他称之为“生命中的巨大成功”。
> 
> 



持续不断的记录，的确是能提升一个人判断力的，这一点在我自己身上就得到了很好的印证。每次的记录，就像是在大脑里划了一道痕迹，会增强人对于某一事件的记忆力和理解程度，当再次面临决策时，人可参考的经验自然也会增加许多。

---

> 只要牛市对他们有利，琼斯他们也不想过早戳破，他是个趋势追随者，对相反的趋势下注会冒很大的风险。
> 
> 



所以，即便知道经济有泡沫，即便知道市场有风险，只要有利可图，就会有大量的人前扑后继。

---

> 如果投资者可以基于心理的原因非理性地购买和出售，他们也会基于体制性的原因非理性地购买和出售，有时则是心理和体制因素的综合。例如，棉农总是在采收后保留部分收成好几个星期，希望价格会涨，但到年末的时候他们将不卖的心理与体制因素相融合了——他们必须得卖掉农作物，否则将受到不利的税收影响。因此，琼斯找出了规律：
> 
> 
> 
> 每年12月份时，棉花市场都会受到大量卖单的冲击，而且市场会在每年1月份反弹。类似的情况也存在于其他商品市场。小牛在其母亲的肚子里孕育成熟需要接近一年的时间，所以牛的供给对价格上涨反应缓慢，因此，供应可能需要几个月的时间才能和需求相匹配，而且牛的期货的上升趋势往往比较持久。或者以股市为例，包含在道琼斯工业指数中的股票往往在每季度的最后一个周五收盘的时候表现比较好，因为那时套利交易商要将他们卖空的股票买回——这些股票是交易商用于对将要到期的期货合约进行套期保值的。
> 
> 



不管是投资策略，还是软件开发，都要和现实生活结合起来，这一点，我近两年的体会特别深。



**自从来到目前这家公司之后，因为开发出来的软件都会很快被投入使用，我逐渐脱离了以前那种完全靠想象去开发软件的工作状态，有了真实用户之后，我会考虑更多实际使用过程当中出现的软件设计问题，以及越来越倾向于亲身奔赴现场去了解用户的操作体验。**



**现场使用系统，跟坐在办公室造数据测进行试，区别真的特别大。近期，我们有一个重点项目要进行第二轮全流程测试，我原本是打算造些数据，然后到东莞厂区找生产和品质经理拉个会议，现场跑一下流程就完事了，好在我部长提出了一个更好的思路：在测试环境造一批与正式环境相似的数据，然后提前打好条码，再去各个现场工作区域进行测试。**



这一轮测下来，就发现了很多细节问题，软件逻辑的小bug尚且不说，值得重点分析一下的问题有这些：



1、由于前端依赖一个开源组件，导致厂区个别无法连接外网的设备，每次打开系统界面时，都会有30～60秒的一个延迟。



2、仓库区域没有覆盖Wi\-Fi，如果不提前进行布局，到时系统上线，就会出现产品无法入库上架的尴尬局面。



3、FQC区域的工控屏特别小，不方便查看系统界面，更严重的问题在于，设备没有连接扫码枪，这会导致品检人员无法扫描条码进行品检操作，而依赖键盘进行手输条码的操作方式，怕是会让品检人员气得拍桌子。

······



还有一些小问题就不一一列举了，**以上列出来的三个问题，坐在办公室开发和测试软件的我们，是完全感知不到的，而在实际生产过程当中，这些问题，对于用户来说，都是足以令他们抵制使用这款软件的主要原因，如果不亲自前往现场测试，提前发现这些问题，到时系统一上线，我们整个部门必定会天天被投诉，忙得焦头烂额。**



今后，我如果要开发自己的量化投资策略模型，也要始终牢记这一点：**策略模型的逻辑要跟符合现实逻辑，要有具体的应用场景，完全依赖于数学公式和个人想象搭建起来的模型，就好比“空中楼阁”，是站不住脚跟的。**
