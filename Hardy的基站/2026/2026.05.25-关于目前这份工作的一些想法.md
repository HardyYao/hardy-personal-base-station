# 1

今天下午突然觉察到一件事，我发现目前的这家公司，对我来说，最大的吸引力，就只剩下——把这边的项目给做完，把这家公司整套制造业的业务流程给玩明白 这件事了。

而且我似乎已经在这种状态当中工作超过半个月了。

对于福利待遇之类的东西，从上次20周年庆典公司的那个骚操作之后，原本就对此不抱多大指望的心，更加凉了一大半。

面对一家福利待遇方面毫无可取之处且没有什么感情基础的公司，在有其他更好去处的情况下，我依然愿意继续留在这里把事情给做完，证明自己是真的对这边的工作内容有点兴趣，而非出于其他考量。

我还挺喜欢自己的这个转变的，越来越清楚自己想要什么。

然后有了经济基础作为托底，也就能够有更多的自主选择权。

真正做自己想做的事情。

# 2

下午刚跟嘉铭宣泄完一波情绪（关于我们部门总监的），晚上我们总监就找我聊天了，还是说那个 Java 开发工作安排的事情，那小伙子最近确实有点离谱了，我都有点看不下去了。

就事论事地讨论了一下，然后头一回听他讲了一些心里话，大概有点理解他的一些思维了。只能说，此人的确有点另类，以至于不太理解常人喜欢轻松愉快生活的追求。

但也没那么反感他了，反正我还留在这里，就只是想把项目给做好，为了实现自己的追求。

他也说，他现在知道我有自己的规划、不用别人盯着，但是另一个 Java 开发的工作得排好，别一天到晚都是我自己在加班，另一个后端却天天没事干。

确实是得给那个小伙子上点压力了，不然他快彻底放飞自我了。

之前我只要给他提个醒，他都会听进去，但最近这段时间，他的状态是有点奇怪，一些很简单的工作却总是来来回回做不完，没什么做事的状态。

我虽然不喜欢给人施压，但也不能任由他这么懒散下去。

# 3

今晚还跟我们总监对了一下系统剩余的功能，感觉更加清晰了，今年下半年把 WMS 给做完，明年上半年花两三个月把 SCM 剩余功能做完，之后再花大半年时间做报表以及去一线了解更多业务知识（当然，今年也还是要抽空多去一线了解业务知识）。

到 2028 年，刚好一切就圆满了，挺神奇的，刚好跟嘉铭所说的时间节点对上了。

# 4

我跟我们总监之间的矛盾，本质上是不同年龄段、不同文化思想之间的矛盾，无关个人。

想到这一层，感觉这个事情也可以画上一个阶段性的句号了，好好做事，这个事情，不值得想太多。

# 5
我们总监对我说：实际上他都帮我们团队三个开发人员做好职业规划了——熟悉制造业的业务流程，达到制造业顾问级别的水平，再加上我们拥有编程基础，就足以避免“国内程序员到 35 岁就被淘汰的命运”。

上周之前，我觉得自己大概率也会往这条路走下去，至少会走相当长一段时间，只不过，上周六晚上郭老师的一番话，开始改变这个命运轨迹。

但，不管最终我选择的是哪一条路，都不会改变我对现有工作的态度，我是在搭建属于我自己的产品，尽管它的所有权不归我，但它的系统逻辑几乎都由我设定，我是它的主要创造者，既然如此，我就会竭尽全力把它做到最好！
