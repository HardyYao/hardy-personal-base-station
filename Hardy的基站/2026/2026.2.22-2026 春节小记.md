# 2月16日（除夕）

跟往年一样，中午去村里祠堂拜神明，然后回家打火锅、吃饭。

比较独特的一点在于，今年这个除夕，我是穿着短袖去祠堂拜的，因为天气实在太热了。

晚上，还是在家看春晚。不过今年没有看完最后一个节目就去睡觉了。也不知道为什么，前几年明知道第二天早上得早起去祠堂拜神明，我也还是坚持要看完春晚、听完《难忘今宵》再去睡觉，仿佛是一种仪式感。而今年，却没有那么执念了，跟老妈去拜完祠堂外面几个神明回来后，就觉得困了，直接就去睡觉了。

# 2月17日（大年初一）

早上7点20分就起床洗漱，然后发现没那么快要去拜，所以去睡了个三十分钟的回笼觉，到差不多九点才去祠堂拜。

调整一下节奏：明年大年初一可以不用那么早起了。

今年的大年初一，我没出门、也没有追剧什么的，就在家看书，看完了《大脑喜欢这样学》这本书，还蛮有收获的。

晚上十点多的时候，二姐找我视频，她跟我说她只要一说“小舅舅”，外甥女就会笑得很开心，她还示范了几次给我看，把我给逗乐了，还不满一周岁的小外甥女笑起来实在是太可爱了，她的笑声也很治愈。

# 2月18日（大年初二）

两位姐姐回娘家了，大姐的两个大外甥和二姐的小外甥女也过来了。

两个大外甥都是十多岁的小伙子了，现在一到我们家就是拿出手机和平板来打游戏，他们现在不喜欢被别人管，我作为过来人，也理解他们的想法，就随他们玩去了。

现在家里人的注意力都集中在了最小的外甥女身上，小孩子变化真大，除夕前两天在这边的时候，小外甥女走路还很不稳，每次她一走路，我都担心她会摔倒。不过才过去没几天，她走路的时候已经稳了很多了。

小外甥女很喜欢“吃”手指，她小姨不想让她这么做，经常干预她的这个行为，结果似乎引起了她的逆反心理，她现在一看到她小姨，就要先把手指往嘴里塞。

大姐调侃道，这小外甥女以后长大了估计也是个“犟种”。

# 2月19日（大年初三）

认识慨睿十几年了，今天第一次去他家做客。

从下午两点半聊到了六点半差不多才回家。

今天跟他聊的话题主要是围绕AI以及数字永生，他的一个观点我觉得十分有意思——碳基生命的存在或许只是为了进化到能够作为开启硅基生命的钥匙。

我则在和他交流的过程中，将之前的一些琐碎想法再次串了起来：

去年，我其实挺长一段时间都觉得挺迷茫的，因为不知道未来在哪里，隐约有种焦虑感。不过在年末进行总结的时候，却发现，这一年，自己也还是做了挺多事情的：为数字生命工程积累了许多高质量的语料、被自己最喜欢的一家软件公司给采访了、工作心态有了比较积极的转变、找到了自己的使命感······

人的大脑需要定期清理缓存，才会有足够的空间去容纳新事物，产生新的灵感，睡觉、放空自己和冥想，都有助于清理缓存。

以前许多需要考阅历和时间才能够想明白的事情，现在借助一个读取了自己足够多语料的AI，就能够在十分钟内，通过几个高质量的问题得到解答。

# 2月20日（大年初四）

早上出门散步时，遇到了小学六年级的楚凤老师。

才知道，她已经退休好几年了，时间过得真快呀！

# 2月21日（大年初五）

回深圳了。

其实我还请了三天假，要到初九才上班，但我想早点回深圳，过几天自由自在的时间。

这次回家，能感觉到，爸妈在餐桌上的态度产生了些许变化，虽偶尔还是会唠叨着想让我们多吃点，搞得大家有些不自在，但比之前已经好了许多了。

当然，这也仅仅是和之前相比而已，实际上对于我来说，还是会感受到些许压力的，尤其是爸总是因为一点小事脸就变黑，关键是他自己还意识不到这一点，每次一看到他脸变黑，就很影响我食欲。

以及他讲事情时动不动就大吼大叫的坏毛病，也依然没有改，我对这一点真的感到很厌恶，也很疲惫。

如果我的家庭氛围足够轻松的话，我是想要多在家待几天的，可惜，那或许只能是个不切实际的幻想，所以，我只能改变自己了，让自己远离那个会让我感到心烦的环境。

刚回家那一天，就被匆匆忙忙地安排了一场相亲，而且最让我反感的是，那天晚上那个人一回家，就跟老妈抱怨：为什么我买完衣服回家了，她却没发微信给他说？

我一天的好心情就被他进门后的这副烂表情给破坏完了，好像我欠他似的。

结果后面相亲的那个人，也压根就不想跟我相处，纯粹就是白费功夫。

我也下定了决心：今后，拒绝家里通过媒人介绍的一切相亲对象。通过亲朋好友介绍的相亲对象，则可以考虑，因为有了亲朋好友的这一层筛选，相对来说还是靠谱一些，不像很多媒人介绍的那样，纯粹就是在浪费我的钱和时间。

# 2月22日（大年初六）

早上，继续看完了前两天追的剧《成家》。

下午，开始看书和写点文字。

能感觉到，现在状态还不太好，在家的时候，吃住是方便一些，但受到某人的情绪干扰也比较多，现在大脑还在清理之前的情绪垃圾。

慢慢来吧，今年要做的事情还有很多，先放空一下大脑，同时也做一下减法，再把原先一些不那么紧要的事情给停掉，彻底从大脑清除，专心做好自己的长期事业。
